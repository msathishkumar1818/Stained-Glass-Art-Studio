Production HTML must NOT contain remote image URLs.

## Image Directories

```
assets/images/hero/          — Full-bleed hero images
assets/images/sections/      — General section imagery
assets/images/gallery/       — Glass art gallery pieces
assets/images/products/      — Product photography
assets/images/about/         — Studio / team / process
assets/images/backgrounds/   — Texture & atmospheric backgrounds
assets/images/testimonials/  — Client portraits (if used)
```

## Approved Sources

- Unsplash (unsplash.com) — Unsplash License (commercial use: ✓)
- Pexels (pexels.com) — Pexels License (commercial use: ✓)
- Pixabay (pixabay.com) — Pixabay License (commercial use: ✓)
- Openverse (openverse.org) — Verify per-image license

## Rules

1. ONE image = ONE usage. No duplicates across pages/sections.
2. Verify commercial use BEFORE downloading.
3. Record EXACT source page URL (not homepage).
4. Rename files descriptively: `hero-cathedral-window.jpg`, not `photo-1234.jpg`.
5. Never use watermarked, editorial-only, or unclear-license images.
